# 이재성 | Backend · Data

웹 서비스와 데이터 처리 기능을 개발합니다.  
API 설계, 데이터 수집·정제, 업무 자동화 프로젝트를 진행했습니다.

## Tech Stack

- Backend: Python, FastAPI, Java, Spring Boot
- Frontend: JavaScript, TypeScript, React
- Database: PostgreSQL, MySQL, Redis
- Tools: Docker, Git, GitHub
